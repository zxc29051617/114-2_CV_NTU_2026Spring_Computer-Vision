Place the bonus folder as:

    object_depth_order_demo.py
    make_depth_order_video.py
    requirements_bonus.txt

    phone_data/
      scene1/
        left.jpg
        right.jpg
    results/
      depth_order_scene1/

The input stereo pair is:

phone_data/scene1/left.jpg
phone_data/scene1/right.jpg

The existing generated result folder is:

results/depth_order_scene1/

2. Environment

Recommended environment:

Python 3.x
numpy==1.24.4
opencv-contrib-python==4.13.0.92
pandas
tqdm
psutil

Install required packages:

pip install -r requirements_bonus.txt

opencv-contrib-python is required because computeDisp.py uses cv2.ximgproc for guided filtering and weighted median filtering.

3. Run bonus demo

From the Stereo Matching_bonus folder, run:

python object_depth_order_demo.py --left phone_data/scene1/left.jpg --right phone_data/scene1/right.jpg --out_dir results/depth_order_scene1 --max_disp 96

An ROI selection window will appear. Select three object regions:

1. Near object region
2. Middle object region
3. Far/background region

Press ENTER or SPACE after each selected ROI, then press ESC after all ROIs are selected.

For reproducing the current generated result without interactive ROI selection, run:

python object_depth_order_demo.py --left phone_data/scene1/left.jpg --right phone_data/scene1/right.jpg --out_dir results/depth_order_scene1 --max_disp 96 --boxes "Object_1:501,254,89,422;Object_2:311,582,134,72;Object_3:139,88,296,287" --no_interactive

7. Method summary

The bonus system captures two horizontally shifted phone images as a stereo pair. It detects ORB feature correspondences, estimates the fundamental matrix with RANSAC, performs uncalibrated stereo rectification, computes disparity using the submitted computeDisp.py algorithm, and ranks selected object ROIs by reliable p75 disparity score.

No OpenCV built-in stereo matching implementation is used.
